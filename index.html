Research

My current focus at Lila Sciences is Self-evolving Agents & Scientific Discovery. In summer 2026, I led a research program on self-evolving terminal agents with Zhongzhi Li, Ruhan Wang, Zongxia Li, and Junyao Yang. The projects below cover dense evaluation, recursive synthesis of executable environments, readable agent harnesses, and stable asynchronous post-training.

Recursive Synthesis for Long-Horizon Terminal Tasks
A recursive verified synthesis pipeline that evolves complete executable task bundles into 37,484 increasingly difficult training tasks across 15 rounds.
Project lead · Data engine · Aug 2026 · Paper · Blog · Data & Models
Stale but Stable
A staleness-adaptive trust region that tightens PPO-style clipping only for high-mismatch tokens, stabilizing fully decoupled asynchronous RL.
Project lead · Agentic RL · Jul 2026 · Paper · Blog · Code
Long-Horizon-Terminal-Bench
Forty-six long-horizon tasks across nine categories, with dense intermediate rewards that measure meaningful progress through sustained terminal workflows.
Project lead · Benchmark · Jul 2026 · Paper · Code · Leaderboard
Harness Handbook
A behavior-first map that helps people and coding agents locate where a harness behavior lives before editing it.
Project lead · Agent systems · Ruhan Wang · Jun 2026
